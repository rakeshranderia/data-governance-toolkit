# Data Governance Toolkit



A practical set of connected frameworks for understanding, governing and using organisational data.

The toolkit is built around three questions:

1. **What is this data and how should it be handled?**
2. **Where did it come from, what happened to it, and where does it go next?**
3. **Who owns the decisions and controls needed to govern it over time?**

That becomes:

**Classify → Trace → Govern**

## Components

### 1. Data Classification & Governance Readiness
A practical method for classifying data and connecting classification to controls such as access, sharing, retention, encryption and AI use.

### 2. Data Lineage & Dependency Mapping
A framework for documenting data movement from source to consumption, including transformations, interfaces, ownership, downstream dependencies and control points.

### 3. Data Governance Operating Model
A lightweight operating model connecting owners, stewards, classification, lineage, quality, access, lifecycle and evidence.

## Core position

Data governance becomes useful when it is connected to the way data actually moves through the organisation.

Classification without lineage can miss propagation risk.

Lineage without ownership becomes documentation.

Ownership without decision rights becomes a title.

The goal is to connect all three.

## Publication philosophy

This material is designed to be:
- practical rather than bureaucratic;
- implementable in stages;
- understandable by both business and technology stakeholders;
- compatible with regulated and non-regulated environments;
- reusable across analytics, integration and AI use cases.
